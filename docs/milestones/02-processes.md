# Milestone 2: Processes

## Goal

Show current Solid Queue process records and heartbeat status.

## Depends on

Milestone 1.

## Deliverables

- List workers, dispatchers, schedulers, and supervisors with available process names, hostnames, PIDs, and heartbeat timestamps.
- Classify heartbeat status using the supported Solid Queue behavior. Show current records only.
- Include responsive table, empty, unavailable-backend, and stale-heartbeat states.

## Complete when

Tests cover each process kind, current and stale heartbeats, empty records, unavailable Solid Queue, and the rendered page.
