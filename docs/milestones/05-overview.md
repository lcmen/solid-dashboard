# Milestone 5: Overview and deferred page states

## Goal

Complete the prototype's Overview page and make deferred Cache analytics states clear.

## Depends on

Milestones 1 through 4.

## Deliverables

- Show current Queue and Cache summaries using supported records and fields.
- Show bounded Queue activity charts derived from retained Solid Queue timestamps and execution records. State the limits of available history.
- Keep Cache analytics and Cache events in the navigation. Explain that event instrumentation is not available yet and show event metrics as unavailable, not zero.
- Use the prototype's period controls only for data that exists in the selected time range.

## Complete when

Tests show that overview values match their source records, chart intervals remain bounded, and missing, empty, and unavailable data states are clear. Compare the layout with the prototype.
